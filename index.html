Practical P13

Choosing Between Flexbox & CSS Grid

Both layout systems complement each other. Use this guide to pick the right engine for the job:

When to use Flexbox (1D)

One Dimension
  • Content-First Layout: Content sizes dictate how much space each item takes.
  • Single Row or Single Column: Navigation bars, form inputs beside buttons, breadcrumbs.
  • Distribution & Alignment: Centering items vertically (`align-items: center`), spacing them out (`justify-content: space-between`).
  • Wrapping Tag Clouds: Elements wrap naturally across rows without needing column alignment.

When to use CSS Grid (2D)

Two Dimensions
  • Layout-First Architecture: You define the strict rows and columns, then place items inside.
  • Card Grids with Consistent Alignments: Items align across both horizontal rows and vertical columns.
  • Spanning Cells: Featured cards or hero banners that span across 2 or more columns/rows.
  • Complex Page Layouts: Newspapers, dashboards, photo galleries, and magazine covers.
