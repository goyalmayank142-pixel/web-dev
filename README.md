# Web Development Portfolio — Practicals (P1–P13)

A responsive, accessible personal portfolio website built step-by-step to demonstrate core web development fundamentals: terminal navigation, Git version control, semantic HTML5, modern CSS styling systems, Flexbox, and CSS Grid.

---

## 📚 Curriculum Structure

### **Module 1: Terminal, Git & GitHub**
- **P1**: Project folder and terminal navigation (`pwd`, `ls`, `mkdir`, `cd`).
- **P2**: Portfolio repository with initial commit.
- **P3**: Feature-branch Git workflow (`git checkout -b`, `git merge`).
- **P4**: Project documentation (`README.md`) and Git version tagging (`git tag`).

### **Module 2: HTML & CSS Foundations**
- **P5**: Semantic bio page (`bio.html`) with `<article>`, `<section>`, `<figure>`, `<aside>`.
- **P6**: Full portfolio structure in semantic HTML (`index.html`).
- **P7**: Design tokens and typography scale with CSS variables (`styles/tokens.css`).
- **P8**: Sticky navigation bar and card overlay with CSS positioning (`styles/layout.css`).
- **P9**: Responsive navbar and card grid using Flexbox (`display: flex`, `flex-wrap`).

### **Module 3: CSS Layout Systems**
- **P10**: Portfolio header and footer with advanced Flexbox (`styles/layout.css`).
- **P11**: Newspaper-style three-column layout with CSS Grid (`newspaper.html`).
- **P12**: Portfolio projects grid with advanced CSS Grid (`repeat(auto-fit, minmax(...))`).
- **P13**: Technical comparison: When to choose Flexbox vs. CSS Grid (`LAYOUT-COMPARISON.md`).

---

## 🚀 How to Run Locally

1. Clone or open this repository in your code editor:
   ```bash
   cd ~/Downloads/deepak
   ```
2. Open any `.html` page in your browser:
   - `index.html`: Main portfolio
   - `bio.html`: Semantic biography
   - `newspaper.html`: 3-Column CSS Grid demo

No build tools or node servers are required—everything is written in standard, modern HTML5 and CSS3.
